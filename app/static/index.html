How it works

Three steps to pure outrage

Type a target
A company or domain like stripe.com pulls their logo from Logo.dev. An @handle grabs that profile photo straight from X, while py: renders a Python term.
Get an instant meme
The logo is trimmed, scaled, and placed right in Grampa's line of fire. Rendered fresh, no sign-up, no watermark.
Use it anywhere
Every meme lives at its own URL. Hotlink it in a README, embed it, or script it with the API.

For developers

A meme endpoint, not a meme site

Every meme is a single GET request that streams back a PNG. No keys, no JSON, no dashboard — just a URL you can drop anywhere.

GET /{search}
Yell at a company by name or domain — fetches and crops their logo.
GET /x/{handle}
Yell at an X user — pulls their profile photo.
GET /gh/{handle}
Yell at a GitHub user — pulls their avatar.
GET /py/{term}
Yell at a Python glossary term — renders the term literally.
GET /img/{image-url}
Yell at an image URL — pass the URL encoded in the path. 
# yell at a company
curl -O https://oldmanyells.at/stripe.com

# yell at an X user
curl -O https://oldmanyells.at/x/elonmusk

# yell at a GitHub user
curl -O https://oldmanyells.at/gh/torvalds

# yell at a Python term
curl -O https://oldmanyells.at/py/free-threading

# yell at an image URL
curl -O https://oldmanyells.at/img/https%3A%2F%2Fexample.com%2Flogo.png
